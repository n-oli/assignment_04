Bootsrap Components Used

Accordion is a bootstrap component that organizes content into collapsible sections. It allows users to expand and collapse sections to view or hide content, making it useful for displaying information in a compact and organized manner.

Modal is a bootstrap component that displays content in a layer above the current page. It is often used for dialogs, forms, or additional information. Modals can be opened and closed by user interaction, providing a focused experience without navigating away from the main content.
